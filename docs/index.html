Skin Scan and Quiz: Documentation

Shopify app jo store par AI Skin Scan, Quick Quiz aur Deep Dosha quiz chalata hai, aur har customer ko uske result ke hisaab se products aur ritual batata hai. Ye page Hinglish mein hai, merchant aur developer dono ke liye.

Code: github.com/SaurabhBhatiaodesk/ai-skin-quiz

1. App kya hai

App ka naam Skin Scan and Quiz hai. Ye Shopify ki embedded app hai: admin Shopify ke andar khulta hai aur storefront par widget theme app blocks se lagta hai. Customer ke answers aur scan server tak app proxy (/apps/dosha-quiz) se jaate hain.

  • Admin: React Router app, Heroku par (prana-ai-skin-quiz).
  • Storefront: theme app extension extensions/dosha-quiz, jisme 4 blocks hain.
  • Database: production mein Postgres (Heroku DATABASE_URL), local par SQLite (prisma/dev.sqlite).
  • Permissions: sirf read_products aur read_themes.

2. Features

AI Skin Scan

Camera ya photo upload. Consent ke baad AI (OpenAI) photo dekh ke visible skin observations deta hai. Photo app store nahi karti. Result mein animated skin map aur product picks aate hain.

Quick Quiz

Kuch chhote sawal. Result mein sirf matching products aate hain, dosha nahi.

Deep Dosha

PRANA spec ke 18 sawal (A = Vata, B = Pitta, C = Kapha). 7 mein se ek result aata hai, saath mein poori reading, ritual aur products.

Floating Skin Scan

Har page par ek floating button (pulse animation ke saath). Click karne par scan popup khulta hai.

Email report

Email dene par report unlock hoti hai aur detailed report email par bhi jaati hai (Resend ya Klaviyo se).

Add to cart

Result se seedha cart mein product daal sakte hain. Jo product cart mein chala gaya, wo list se hat jaata hai.

3. Store par setup (merchant ke liye)

  1. App install karo. Admin mein Quizzes & Skin Scan kholo.
  2. Naya quiz banao (Combined, Single ya Only Skin Scan). Questions, products ki mapping, design aur texts set karke Save karo.
  3. Deep Dosha quiz ke liye editor mein "Load PRANA questions" dabao, phir Save karo. Isse client ke doc wale 18 sawal aur sahi tags lag jaate hain.
  4. All quizzes page se quiz ka widget code copy karo.
  5. Online Store → Themes → Customize mein page kholo, Add block se app block lagao, aur widget code paste karo.
  6. Floating button ke liye theme editor ke App embeds mein "Skin Scan and Quiz" on karo. Uska rang, label aur shape Skin Scan appearance page se badlo.
  7. Skin Scan ke liye Global Settings mein OpenAI key daalo aur Scanner health page par check karo ki scan ready hai.
Dhyan do: agar Deep Dosha ke percentages ajeeb lagein (jaise 13 Vata answers par 84%), to iska matlab hai ki store par purane questions save hain. "Load PRANA questions" dabake Save karo.

6. Deep Dosha rules (PRANA spec)

18 sawal hain. Har answer 1 point deta hai: A = Vata, B = Pitta, C = Kapha. Rules isi order mein check hote hain, aur jo pehle match ho wahi result hai:

#RuleResult
1Kisi ek dosha ke 12 ya zyada pointsVata / Pitta / Kapha
2Do doshas mein dono ke kam se kam 5 points, aur dono ka total 15 ya zyada (order: Vata-Pitta, Vata-Kapha, Pitta-Kapha)Dual dosha
3Teeno doshas 5 se 7 points ke beechTridoshic (balanced)
4Baaki case mein sabse zyada points wala doshaSingle dosha
5Upar tie ho toDual dosha

Agar kuch answers kisi dosha ke nahi hain (neutral options), to thresholds total points ke hisaab se scale ho jaate hain. Har combination ka ek hi result aata hai. Test scripts/check-dosha-rules.mjs saare 190 combinations check karta hai.

7 results: vata, pitta, kapha, balanced (Tridoshic), dual-vata-pitta, dual-vata-kapha, dual-kapha-pitta. Saara text app/dosha-content.ts mein hai.

7. Product recommendations

  1. Merchant mapping pehle: editor mein jo product mapping banayi hai, wahi pehle dikhegi.
  2. Ritual fallback: agar Deep Dosha (personalized mode) mein koi mapping nahi mili, to doc ke 6 ritual products dikhte hain. Store mein ye products handle se, phir title se, phir title ke words se dhoondhe jaate hain.
  3. Quick Quiz: sirf mapped products dikhte hain. Agar koi match na ho to saaf message aata hai.

Har product ke saath "Morning · Night" ya "Once every 2 weeks" jaisa label aata hai, aur Add to cart button bhi.

8. Email report

  • Email dene se pehle Deep Dosha ki guide aur products locked rehte hain (agar quiz mein email capture on hai).
  • Resend: server par RESEND_API_KEY aur REPORT_FROM_EMAIL set ho to poori report HTML email mein jaati hai. Pehle Resend mein sending domain verify karna hoga.
  • Klaviyo: Resend set na ho aur KLAVIYO_PRIVATE_API_KEY + KLAVIYO_SHOP set ho to event Klaviyo par jaata hai, aur email Klaviyo flow bhejta hai.
  • Ek report ki ek hi email jaati hai, chahe customer do baar click kare. Email fail ho to dobara try karne par phir se bheji jaati hai.
  • Status Collected emails page par dikhta hai.

11. GitHub workflow

Repo: SaurabhBhatiaodesk/ai-skin-quiz. Main branch: main.

  1. Kaam shuru karne se pehle hamesha git pull karo, taaki doosre logon ke changes aa jayein.
  2. Code badlo. Widget badla ho to npm run build:widget zaroor chalao.
  3. npm run check, npm run typecheck aur npm run lint pass hone chahiye.
  4. Commit karo aur push karo.
git add -A
git commit -m "Kya badla, ek line mein"
git push origin main
Dhyan do: adhoora kaam commit mat karo. Ek baar kisi tool ne adhoori snippet edit push kar di thi, jisse admin preview mein raw Liquid text dikhne laga tha.

Ye file docs/index.html hai. GitHub par repo → Settings → Pages → Source: "Deploy from a branch" → Branch main, folder /docs → Save. Kuch minute baad page https://saurabhbhatiaodesk.github.io/ai-skin-quiz/ par khulega. Repo private ho to Pages ke liye GitHub plan check karo.

12. Deploy

Deploy do jagah hota hai: server (Heroku) aur Shopify extension. Jo badla hai, uske hisaab se dono ya ek karo.

Kya badlaKya deploy karna hai
app/ ka server code, admin pages, scoring, emailHeroku
Storefront widget, blocks, snippet, CSSShopify extension (aur Heroku bhi, kyunki admin preview aur iframe embed server se same files lete hain)

Heroku

heroku login
git push heroku main

Heroku build ke time npm run build chalta hai, jo pehle build:widget chalata hai. Start par npm run setup database migrate karta hai.

Shopify extension

npx shopify app deploy --allow-updates --message "Kya badla"
Check: deploy ke baad store ka quiz page kholo aur ek baar quiz poora chala ke dekho. Admin mein Quiz editor aur Skin Scan appearance ka preview bhi kholo.
